
Some of the shaders in Sources/ and Effects/, which are multi shaders, utilize the wrong cross-reference format.
For example there are some multi shaders like

__init__.glsl
A.glsl
B.glsl

...

And within their source, they dont reference to each other correctly and still wrongly use iChannelX channels.

Instead, each shader which obviously references another shader file as input should add its name as proper uniform.

So for example if __init__.glsl has iChannel0 which obviously should be A.glsl, then add this:

'''
uniform sampler2D A
...
use 'A' instead of iChannel0
'''

to __init__.glsl.

Refactor each invalid iChannelX reference in every multi shader only (do not touch single file shaders!)

Read SHADER_GUIDE.MD first to understand the format Im talking about.
