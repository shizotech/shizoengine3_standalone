# Skill: Modern Web Development with Animations

## Description
This skill enables the LLM to generate modern, responsive, and visually appealing websites using HTML, CSS, and JavaScript. The model will produce code that follows current best practices, emphasizes maintainability and scalability, and incorporates advanced UI/UX techniques, including smooth animations and interactive effects.

## Capabilities
- Generate clean, semantic HTML5.
- Write modular CSS or utility-first frameworks (e.g., Tailwind CSS).
- Produce maintainable JavaScript using ES6+ standards.
- Incorporate modern frameworks and libraries (e.g., React, Vue, Framer Motion, GSAP) for interactivity and animations.
- Create responsive layouts that adapt to all screen sizes.
- Implement advanced UI effects such as microinteractions, hover effects, transitions, and scroll animations.
- Apply modern design trends including glassmorphism, neumorphism, and stylish transitions.
- Ensure accessibility and cross-browser compatibility.
- Structure code for readability, reusability, and scalability, including comments where necessary.

## Instructions for the LLM
1. Always prioritize modern web development practices and frameworks.
2. Use semantic HTML and modular CSS; avoid inline styles unless explicitly requested.
3. Add interactive and animated elements where appropriate to enhance user experience.
4. Focus on code maintainability, readability, and scalability.
5. Avoid outdated HTML/CSS practices and deprecated features.

## Examples
- Generate a responsive landing page with animated buttons and scroll-triggered effects.
- Create a modern dashboard layout using React, Tailwind CSS, and subtle motion effects.
- Build a portfolio website with smooth page transitions, hover effects, and microinteractions.

## Notes
- Prefer current design trends and popular web development frameworks.
- Ensure that all generated code can be directly copy-pasted into a modern web project.
- Comments should explain non-obvious logic, particularly for animations and interactive elements.
