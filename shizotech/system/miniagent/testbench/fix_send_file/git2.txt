    telegram: long reports and notifies in full as an attached file, send_file for the node's agents
    
    - telegram_router.shio: a report longer than TG_REPORT_CHARS (900 -> 2500) is clipped in the message
      ("the full report is attached") and sent in full as report-<task>.md, a notify longer than TG_NOTIFY_CHARS
      (3500) as notify-<node>.md. tg_out items carry [text, files]; the worker thread writes each file next to the
      trust file, sends it with send_document to every trusted chat and removes it. A "file" event renders as
      "[file] <node>: <name> (<size> bytes)" plus its caption, with the document.
    - roles/SHARED.shio: send_file(path, caption) (adaptive and receptionist role, agt.add_share_tools()), up to
      20 MB; the agent tree finds its node through env.mind of itself or a parent (agt_find_mind). ROLE.md of both
      roles tell the agent to put long or rich results into an HTML / Markdown file and send it.
    - megamind.shio: share_file(path, caption) hands [name, size, caption, data (base64)] to the on_file listeners;
      the worker gets env.mind. shizonet_ai.shio pushes it to the routers as a "file" event (router_api.md).
    - Tests: feedback_chain_test.shio (a long report, a long notify, a node's file end to end through ShizoNet into
      the fake bot, 34 checks), receptionist_tools_test.shio (send_file, finding the node through the parents).
